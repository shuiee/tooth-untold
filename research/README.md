# Research folder

A copy of the team's Google Drive folder **MDE Studio - Data Viz - Dental**, with the same subfolders. These are reading and candidate sources for extending the story. The page does not read anything in this folder. The datasets it does use are in `source/datavis data/`, and `build_data.py` documents how each one is filtered.

| Folder | What's in it |
|---|---|
| `Artificial Interventions/` | Dental care from antiquity to today: papers on Etruscan, Roman and Palaeolithic dentistry; the Adult Dental Health Survey 2009 reports and tables; NHS dental patient and contract data (2019/20–2024/25); health-workforce tables (`hlth_rs_prs…`, `HLTHRES_185_EN.xlsx`); `interventions.csv` and `EU_dental_interventions.xlsx`. |
| `Human Correlations/` | `timeline_events_display.csv`, historical events for the timeline. |
| `Methodologies/` | How wear and stress lines are scored (Bas 2021 macrowear; ages of linear enamel hypoplasia formation) and a hypoplasia reference image. |
| `Morphology (Wear, Caries, LEH)/` | Global History of Health Project: the full Europe and Western Hemisphere spreadsheets, site context tables, variable names and both codebooks. |
| `Particulates/` | Papers on lead, mercury and other trace elements in bones and teeth, and on what dental calculus preserves (plants, particles, proteins); `particulates_metals_dataset.csv`. |
| `Pathogens/` | AncientMetagenomeDir sample tables, `pathogen_reference.csv`, the rest of the Kocher et al. 2021 supplement, and a paper on Copper Age calculus. |
| `PROTOTYPE DRAFT/` | `statistical tooth.mov`, a screen recording of an earlier version of the prototype. |

**Not copied**, because the repository already has them:
- the six datasets in `source/datavis data/`, which are byte-identical to the Drive copies;
- `statistical-tooth-draft.zip` and `Methodologies/statistical-tooth/`, earlier versions of this project's code;
- the second copies of `Europe_categorial variable names.pdf` and `GHHP_Codebook-08-25-051[1].pdf` (kept in `Morphology`).

The tooth models from `Teeth OBJs/` are in `source/teeth models/`.

**Before this repository is made public**, remove the journal articles (they are copyrighted; cite them instead) and check the terms of each dataset.
